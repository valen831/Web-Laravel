📋 Tentang Proyek

V-Store adalah platform e-commerce sepatu yang menyediakan koleksi sepatu lokal dan internasional terbaik — dari sneakers kasual hingga running shoes premium. Dibangun dengan Laravel dan Vite, V-Store menawarkan pengalaman belanja yang modern dan responsif.

🚀 Instalasi & Setup

1. Clone & Install

git clone https://github.com/username/v-store.git
cd v-store
composer install
npm install

2. Konfigurasi .env

cp .env.example .env
php artisan key:generate
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=vstore
DB_USERNAME=root
DB_PASSWORD=

3. Migrasi & Jalankan

php artisan migrate --seed
php artisan serve    # Terminal 1
npm run dev          # Terminal 2
